# La Muerte es una Fiesta

Landing page informativa de la exposición **La Muerte es una Fiesta**, de Daniel Bagnara Mena. Presenta información sobre la obra, el artista y su equipo, además de entrevistas, algo de portafolio, etc. Está pensada como punto de acceso para quienes llegan al proyecto mediante un código QR.

El sitio está publicado en GitHub Pages: [lamuerteesunafiesta.github.io/lamuerteesunafiesta](https://lamuerteesunafiesta.github.io/lamuerteesunafiesta/).

Los derechos del proyecto y de esta landing page pertenecen a Daniel Bagnara Mena y a su equipo de trabajo.
